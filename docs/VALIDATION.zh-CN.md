# 兼容性与验证

[English](VALIDATION.md) | **简体中文**

| 版本 | 验证情况 |
| --- | --- |
| Jetsam 1.1 与 CameraUI 0.1 | 在 iPad7,5、iPadOS 18.7.2（22H124）、rootful 环境、ElleKit 1.2 上进行实机测试。相机服务采用了专项限额，相机功能反馈已恢复。 |
| Jetsam 1.2 与 CameraUI 0.2 | 已使用 iPadOS 18.0 部署目标编译为 arm64。软件包限定 iPad7,5，系统版本不低于 18.0 且低于 19.0。尚未完成这两个版本的实机安装或跨系统版本相机测试。 |

每增加一个测试版本，应记录系统构建号、越狱环境、服务实际限额、前后预览和拍照结果、录像保存及回放、第三方采集和卸载恢复结果。不要仅凭安装成功就认定运行时兼容。
